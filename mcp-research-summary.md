The Model Context Protocol (MCP) is an open standard, introduced by Anthropic in November 2024, that standardizes how AI applications connect to external systems — data sources like local files and databases, tools like search engines and calculators, and specialized prompts and workflows. The best mental model is the one the official documentation uses: MCP is a "USB-C port" for AI applications. Instead of building and maintaining a bespoke integration for every data source, you write (or reuse) an MCP server that exposes your data and tools, and any MCP-capable client — Claude Desktop, ChatGPT, VS Code's Copilot Chat, Cursor, and many others — can connect to it. Everything lives in the open: the specification, the protocol schema, and the official documentation are maintained at https://modelcontextprotocol.io and in the GitHub organization `modelcontextprotocol` (https://github.com/modelcontextprotocol), which also hosts the open-source repository of reference MCP servers, the Inspector visual testing tool, and official SDKs for TypeScript, Python, Java, Kotlin, C#, Go, Rust, Swift, and PHP. In this talk I'll cover what MCP is, where the official resources live, and the four follow-ups our team should tackle: evaluating server examples, drafting a client integration spike, doing a security review of adoption, and comparing MCP host applications.
